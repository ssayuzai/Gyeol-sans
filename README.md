# 결고딕 (Gyeol Sans)

현대 한글 11,172자를 모두 담은 무료 한글 고딕 폰트입니다. Light, Regular, Bold 세 가지 굵기가 있습니다.

- 다운로드: `download/` 폴더 (TTF, OTF, 웹폰트 ZIP)
- 버전: 1.102
- 제작: 이윤재

## 사용 범위

- 개인·상업적 사용, 로고·BI·CI, 웹폰트, 앱·게임·PDF 임베딩, 원본 그대로 무료 재배포: 가능
- 폰트 파일 판매, 폰트 파일 수정·변형·다른 폰트와 결합: 금지
- 출처 표기(결고딕 · 제작 이윤재)는 권장 사항이며 필수는 아닙니다.
